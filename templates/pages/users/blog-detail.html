Les bases de Flask pour débutants

Par Admin · 12 Août 2026 · 5 min de lecture

📘

Flask est un micro-framework Python très apprécié pour sa simplicité et sa flexibilité. Il permet de créer rapidement des applications web sans imposer une structure trop rigide, ce qui en fait un excellent choix pour débuter le développement web côté serveur.

Installation

Avant de commencer, il est recommandé de créer un environnement virtuel puis d'installer Flask via pip. Cela permet de garder les dépendances de votre projet isolées du reste du système.

Créer sa première route

Une application Flask repose sur la notion de routes : chaque route correspond à une URL et à une fonction Python qui définit ce qui doit être renvoyé lorsque cette URL est visitée. C'est le point de départ de toute application.

Les templates

Flask utilise le moteur de templates Jinja2 pour générer du HTML dynamique. Cela permet de séparer la logique métier de la présentation, et de réutiliser des blocs communs comme l'en-tête ou le pied de page entre plusieurs pages.

Pour aller plus loin

Une fois les bases maîtrisées, il devient possible d'ajouter une base de données, une gestion des utilisateurs ou encore un espace d'administration, comme celui utilisé pour gérer les articles de ce blog.
